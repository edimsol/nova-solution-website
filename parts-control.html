FCM
송풍기의 모든 운전 정보를
실시간 계측·제어합니다.

풍량, 정압, RPM, 진동, 전력, 소음 등 팬의 모든 운전 데이터를 실시간으로 읽어내고, 현장 조건에 맞춘 가변 제어와 공진 회피를 스스로 수행합니다.

01 / AIRFLOW

실시간 풍량 정밀 제어

요구 풍량(Set Airflow)에 맞춰 인버터 및 모터 속도를 능동 제어하며, 여러 대의 팬이 병렬 운전(Parallel Operation)할 때도 전 장비에 균일한 풍량을 분배합니다.

  • ±5% 고정밀 실시간 풍량 데이터 산출
  • 다중 병렬 팬 간 균일 풍량 제어 (Uniform Airflow)
  • 부하 변동에 따른 최적 에너지 관리
02 / PRESSURE

계통 정압 분석 및 차압 유지

공조 덕트 계통의 정압 변동 패턴을 실시간 추적하여 필터 막힘, 로터, 댐퍼 등 주요 구성품의 부하 상태를 진단하고 이상 발생 시 즉각 경보를 발생시킵니다.

  • 계통 정압 변동에 따른 운전 상태 해석
  • 필터 및 댐퍼 상태 모니터링 & 알람
  • 설정된 HVAC 시스템 운전점 자동 유지
03 / PREDICTIVE

진동 기반 공진 회피 & 예지보전

팬과 모터의 진동(속도/가속도 RMS)을 연속 모니터링하여 공진 주파수 영역 진입을 사전에 회피하고, 베어링 이상 마모를 조기에 감지하여 불시 정지 사고를 방지합니다.

  • 공진 회피 기능 (Resonance Avoidance)
  • 진동 스펙트럼 분석 기반 상태 기반 보전(PdM)
  • 설비 고장 및 공정 셧다운 원천 차단
04 / INTUITIVE

직관적 대시보드 & 한계 경보

  • 온도·습도·밀도 등 공기 조건 자동 보정
  • 진동·RPM·전력 상한값 안전 보호 알람

요구 온·습도에 맞춰 냉·온수 밸브와 가습량을 0~100% 연속 비례(PID) 제어하여 불필요한 과냉각과 재열 손실을 방지합니다.

  • 냉수·온수 코일 밸브 고정밀 PID 제어
  • 가습 유량 비례 제어로 습도 헌팅 방지
  • 공조기 코일 입·출구 열량 실시간 계측
03 / VARIABLE SPEED

팬 풍량 제어 [ CAV / VAV 제어 ]

정풍량(CAV) 제어와 생산 부하 연동형 가변풍량(VAV) 제어를 지원하여, 필요 시점에 최적 풍량만을 공급함으로써 송풍 동력을 절감합니다.

  • 정풍량(CAV) & 가변풍량(VAV) 자동 절체
  • 인버터(VFD) 주파수 동적 가변 제어
  • 실내 차압 및 요구 환기량 기반 속도 보정
04 / HEAT RECOVERY

열교환기 효율 [ 운전 Mode 제어 ]

배기(EA)로 버려지는 폐열을 회수하는 전열/현열 열교환기의 바이패스 댐퍼와 운전 모드를 능동 전환하여 열회수 효율을 극대화합니다.

  • 전열/현열 교환 효율 실시간 감시
  • 외기 조건별 바이패스 댐퍼 자동 개폐
  • 동절기·하절기 환기 열손실 최소화
05 / SMART MAINTENANCE

필터 스마트 관리 [ 차압 정보 제공 ]

프리·미디엄·헤파 필터 각 단의 전후단 차압을 상시 감시하여 필터 분진 막힘 상태를 진단하고 교체 주기를 사전에 예지 안내합니다.

  • 필터 단별 실시간 차압 모니터링
  • 막힘 기준 도달 시 교체 알람 자동 발생
  • 필터 오염에 따른 송풍 팬 풍량 자동 보상
