02. 로고: 동일 형상의 SVG 3종

사용자가 지정한 원본은 nova-symbol-source.png입니다. 보존 파일은 원본 PNG snapshot, 준비 자산 비교는 로고 미리보기에서 확인합니다. 텍스트 “NOVA SOLUTION”까지 새로 그리는 작업이 아니라 지정된 심볼의 벡터화입니다.

현재 컬러용

원본은 거의 균일한 밝은 청록색이며, 내부 픽셀의 중앙값은 RGB(70, 195, 230), #46c3e6입니다. 원본의 매우 미세한 색 변화를 두 지점 그라디언트로 복원했습니다. 위 색상 띠는 복원 측정값의 양 끝 RGB를 사용합니다.

Light · #fefefe

심볼의 모든 불투명 도형을 #fefefe로 통일. 어두운 배경에서 쓰는 밝은 심볼이며 투명 배경을 유지합니다.

Dark · #242424

심볼의 모든 불투명 도형을 #242424로 통일. 밝은 배경에서 쓰는 어두운 심볼이며 투명 배경을 유지합니다.

  • 세 파일의 viewBox, 경로 형상, 여백, 비율을 일치시킵니다. 단색 변형은 색상만 달라야 합니다.
  • 실제 SVG 벡터 path/shape로 구성하고, PNG를 base64 image로 감싼 파일로 대체하지 않습니다. 외부 이미지·외부 폰트·스크립트 의존성을 넣지 않습니다.
  • 원본의 끊어진 부분·겹침·음각 공간을 의도 없는 연결로 바꾸지 않습니다. 저해상도·확대 비교 모두에서 윤곽을 검토합니다.
  • 투명 배경을 유지하고 밝은/어두운 배경에서 각각 확인합니다. 컬러용은 측정한 청록색과 미세한 색 변화, light/dark는 지정된 단일 fill 색이 기준입니다.
  • 파일의 실제 이름·경로, 원본 대비 확인 결과는 로고 미리보기와 보존 manifest를 따릅니다. 이 문서는 아직 운영 참조가 교체됐다고 주장하지 않습니다.

향후 운영 연결 대상

11개 HTML의 헤더·푸터, 공통 partials, 홈 진입 연출, favicon 참조를 한 번에 검토합니다. 헤더가 어둡다고 무조건 단색으로 바꾸지 않고 디자인 맥락에 맞는 준비 자산을 사용하되, Light/Dark 이름은 배경 테마가 아니라 심볼 자체 색입니다. light 파일에 기존 filter:brightness(0) invert(1)를 중복 적용하지 않도록 홈 진입 연출 CSS도 확인합니다.

03. novascroll: 자체 구현할 스크롤 표시

미구현 명세라이브러리 미사용native scroll 유지

공개 명칭은 novascroll. Apple 방식처럼 콘텐츠 위에 가볍게 겹쳐 보이고 활동이 끝나면 숨는 스크롤 표시를 자체 JavaScript/CSS로 구현합니다. OverlayScrollbars는 동작과 시각적 느낌의 벤치마크이며, 패키지를 설치·복사·내장하거나 래핑해 이름만 바꾸지 않습니다.

콘텐츠의 실제 이동은 브라우저의 native scrollTop/scrollLeft에 맡깁니다. 가짜 transform 스크롤·자체 관성 엔진으로 치환하지 않습니다. 기존 휠, 터치, 키보드, 앵커, 스크롤 스냅, 포커스 이동이 작동하는 위에 표시와 thumb 조작만 추가합니다.

공간·시각·접근성 계약

  • 레이아웃 차지 폭 0. track/thumb는 overlay로 배치합니다. 표시/숨김 때문에 본문 폭, 줄바꿈, 카드 폭, 헤더 정렬이 변하지 않습니다. scrollbar-gutter:stable로 전용 공간을 남기지 않습니다.
  • 디자인 기본값은 둥근 6px thumb와 충분한 대비의 light/dark 색상. 포인터 조작 hit area는 시각 두께보다 크게 16px로 잡고 thumb 이외의 overlay 영역은 pointer-events:none으로 둡니다. 양축 교차 영역에서 입력 충돌을 피합니다.
  • thumb 길이는 clientSize/scrollSize 비율, 최소 28px. offset은 실제 scrollTop/Left의 진행률로 계산하고 끝 위치를 정확히 맞춥니다.
  • thumb에는 축별 접근성 이름, scrollbar 역할, aria-controls·aria-orientation·aria-valuemin/max/now를 연결합니다. 해당 축 방향키는 점진 이동, PageUp/Down은 한 화면 단위, Home/End는 처음/끝. 키 조작은 thumb에 포커스가 있을 때만 직접 처리합니다.
  • 운영 문서 전체의 방향키를 novascroll이 전역으로 가로채지 않습니다. 입력·select·textarea·contenteditable·모달·메뉴·모델 뷰어의 키 이벤트를 침범하지 않습니다.
  • native scrollbar를 숨기는 클래스는 초기화 성공 후에만 붙이고 destroy/실패 시 제거합니다. JavaScript를 끄거나 초기화가 실패하면 브라우저 기본 scrollbar와 스크롤이 남아야 합니다.
  • 모션 감소에서는 표시·숨김 효과를 최소화합니다. 강제 색상/고대비 모드에서는 식별 가능한 시스템 색상을 사용하거나 native 표시로 돌아갑니다.
  • 버튼·링크·폼 입력 위에 보이지 않는 큰 클릭 방해 레이어를 만들지 않습니다. thumb의 실제 hit area 외의 포인터는 원래 콘텐츠로 통과합니다.

아래는 향후 자체 모듈의 최소 계약입니다. 전용 scroll viewport를 새로 만들어 내용을 재부모화하기보다 기존 스크롤 요소를 대상으로 사용합니다.

instance.refresh(); // 표시·크기·스크롤 범위 재계산
instance.destroy(); // listener·observer·표시 DOM·숨김 클래스 복구

접근성·입력 제약 목록을 리뉴얼 체크리스트에 가져옵니다. 신규 novascroll이 현재 모달 포커스 트랩 부재나 홈 전역 키 간섭을 더 악화시키면 안 됩니다. 스크롤 연결에 직접 필요한 충돌은 같은 변경에서 해결하고, 별도 디자인·폼 서버 개선은 범위를 분리해 관리합니다.

캐시와 배포 자산

향후 자체 코드의 기본 경로는 assets/novascroll/novascroll.js, assets/novascroll/novascroll.css로 두고 로딩 순서를 공통 script.js 초기화보다 앞에 둡니다. 현재 11개 HTML 배포 검사는 유지하되 novascroll 자산은 명시적 복사 대상으로 추가합니다. cache busting은 기존 styles.css/script.js와 같은 commit SHA 정책을 적용합니다. OverlayScrollbars vendor 파일·CDN·npm 의존성은 추가하지 않습니다.

05. Pretendard를 사이트 기본 폰트로 내장

현재 미설치향후 self-host

Pretendard 공식 저장소의 Variable WOFF2를 그대로 가져와 로컬 자산으로 서비스합니다. 브라우저가 Google Fonts·jsDelivr 등 외부 CDN에서 가져오는 형태를 기본 경로로 사용하지 않습니다. 확인한 공식 variable CSS는 45–920 weight 범위와 font-display:swap를 사용합니다. 배포할 릴리스의 원본 파일·버전·SHA-256·수집일을 함께 기록해 재현 가능한 자산으로 고정합니다.

항목향후 구현 규격
폰트 경로assets/fonts/pretendard/PretendardVariable.woff2. 공식 원본 variable 파일을 유지하며 이번 단계에서 임의 서브셋/재가공하지 않음.
라이선스공식 SIL Open Font License 1.1과 저작권 표시를 assets/fonts/pretendard/LICENSE.txt에 포함하고 배포본에도 함께 보관. 공식 LICENSE 기준.
font-facefamily “Pretendard Variable”, normal style, 공식 파일의 weight 범위, font-display:swap, 상대 local WOFF2 src. 웹폰트 실패 시 즉시 시스템 fallback으로 읽을 수 있어야 함.
기본 stack"Pretendard Variable", Pretendard, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Malgun Gothic", sans-serif. 본문과 버튼·input·select·textarea에 기본 적용.
현재 강제 규칙 교체styles.css 1줄 Noto import 제거. 46–47줄의 body 및 모든 자식/가상요소 Noto !important를 Pretendard 기본 상속 구조로 교체. 뒤쪽 Noto 직접 선언도 검색해 변경. 기술 코드 등 명시적 monospace 사용은 실제 필요가 있는 요소만 별도 유지.
외부 연결 정리index/solutions의 Google Fonts preconnect 제거. 일반 사이트 렌더링에서 fonts.googleapis.com/fonts.gstatic.com 요청이 발생하지 않는지 확인.
로드·레이아웃font-display:swap으로 빠른 fallback 표시. 폰트 완료 시 novascroll/슬라이더의 치수 갱신과 기존 deep-link 정렬을 수행. 무리한 전체 무게 preload 대신 실제 사용하는 variable 파일 하나만 필요 시 preload.
버전 추적공식 릴리스/commit URL, 원본 상대 경로, license 파일, 파일 hash를 한 manifest에 기록. 외부 “latest” URL을 런타임으로 사용하지 않음.

공식 근거: Pretendard Variable CSS, 라이선스. swap의 fallback/교체 동작은 MDN font-display 참고. 이 문서는 폰트를 다운로드·포함했다는 완료 증거가 아닙니다.

build-pages의 WOFF2 복사 규격

현재 scripts/build-pages.mjs의 CSS/JS 자산 regex는 이미지·bin·glb만 처리하므로 @font-face URL 추가만으로 배포되지 않습니다. 향후에는 Pretendard 폰트·LICENSE와 novascroll JS/CSS를 명시적 배포 자산 manifest로 지정하여 dist에 경로 그대로 복사합니다. manifest의 파일 존재·assets 경계·일반 파일 여부를 검사하고 누락 시 빌드를 실패시킵니다. 결과 로그의 “image assets”도 실제 포함된 자산 유형을 반영하도록 바꿉니다.

HTML의 preload와 CSS의 font src는 같은 로컬 파일을 가리켜 중복 요청이 없어야 합니다. 폰트 URL에도 고정 버전/commit 기반 갱신 규칙을 적용해 기존 캐시가 남지 않게 합니다. 신규 파일 404, 잘못된 MIME, 라이선스 누락, 용량이 0인 WOFF2는 배포 검증 실패 조건입니다. 보존 문서/원본 snapshot이 운영 artifact에 실수로 포함되지 않는 기존 경계는 유지합니다.

검증 환경과 배포 단계

현재 Chrome/Edge/Firefox/Safari 계열과 실제 iOS Safari·Android Chrome에서 native 스크롤 차이를 확인합니다. 자동 테스트는 timer·상태·치수·manifest처럼 회귀 위험이 큰 계약 중심으로 작성하고, 지도/3D/스크롤 느낌은 실제 입력으로 확인합니다. 환경을 사용하지 못한 경우 통과로 표시하지 않고 미검증으로 남깁니다.

소스 보존본을 고정한 상태에서 개발 브랜치에 구현하고 로컬 확인 → 배포 artifact 확인 → 사이트 반영 순으로 진행합니다. main push는 현재 Pages 배포를 실행하므로, 운영에 반영할 변경과 커밋 범위를 검토한 뒤 수행합니다. Cloudflare 이메일 변환·beacon의 실제 운영 응답 차이는 공통 운영 기록 및 운영 대조 근거를 참고하되 DNS/TLS/캐시 설정이 검증됐다고 간주하지 않습니다.

07. 근거와 공식 참고 문서

2026-10-08에 조회한 공식 소스를 참고했습니다. benchmark의 옵션/기능은 자체 모듈의 설치 증거가 아니며, 다음 명세의 1600ms 및 적용 영역은 이 프로젝트 요구에 따라 정했습니다.

  • OverlayScrollbars npm — 사용자가 지정한 벤치마크.
  • OverlayScrollbars 공식 저장소 — native 스크롤을 유지하는 overlay 표시, 스크롤 스냅·여러 입력 방식과의 공존을 비교할 참고. 소스·라이브러리를 가져오는 계획은 없음.
  • Pretendard 공식 저장소 — self-host할 원본 자산의 출처.
  • 공식 Pretendard Variable CSS — variable family, weight 범위, 로컬 WOFF2 구성 확인.
  • Pretendard LICENSE — 폰트 배포 시 함께 보관할 공식 OFL·저작권 원문.
  • MDN font-display — swap 및 fallback 표시 동작.

현재 기능의 사실 근거는 외부 라이브러리 소개가 아니라 공통 기능 문서와 그 문서의 snapshot/ 소스 링크입니다. 운영 응답 확인과 로컬 브라우저 확인은 운영 대조·브라우저 확인 기록으로 분리합니다.
