재생 정책

현재 섹션의 영상 하나만 로드·재생합니다. 탭이 숨겨지거나 메뉴를 열면 일시 정지하고, 동작 줄이기·데이터 절약·배터리 부족 시 정지 배경을 사용합니다. 느린 네트워크에서는 정지 배경으로 시작하며 명시적으로 선택한 경우에만 현재 페이지에서 재생합니다. 자동 재생이 거부되거나 영상 로드에 실패하면 JPG를 유지합니다.

배경 정지 버튼은 로고 효과도 함께 중단합니다. 흰색 SVG 로고 주변의 공기 흐름·데이터 효과는 처음 4초 후 2.4초 동안 재생한 뒤 14초 쉬고 반복합니다.
